# Glosario Agrofinanciero - Agrobanco

Este glosario proporciona ayuda contextual dentro de la aplicación para términos que pueden resultar complejos para el usuario rural.

| Término | Definición para el usuario | Uso en App |
| :--- | :--- | :--- |
| **Tasa E.A. (Efectiva Anual)** | Es el costo real que pagas por un préstamo o el interés real que ganas por tus ahorros en un año completo. | Módulo Ahorros / Créditos |
| **Cronograma de Pagos** | Es el calendario que te dice exactamente qué fecha debes pagar y cuánto dinero corresponde a cada cuota. | Módulo Créditos |
| **Saldo Disponible** | Es el dinero que puedes usar en este momento. No incluye depósitos que aún están en verificación. | Dashboard / Ahorros |
| **TEA (Tasa Efectiva Anual)** | (Sinónimo de Tasa E.A.) Es el porcentaje principal para comparar qué tan caro es un crédito. | Módulo Créditos |
| **Garantía Mobiliaria** | Bienes (como maquinaria o ganado) que aseguran el pago de tu crédito. | Detalle de Crédito |
| **Periodo de Gracia** | Tiempo durante el cual no pagas el capital del préstamo (solo intereses o nada), útil mientras esperas la cosecha. | Módulo Créditos |
| **Token Digital / PIN** | Clave de seguridad de 6 números que autoriza tus transferencias de forma segura. | Transferencias / Pagos |

# Preguntas de Validación para el Product Owner (Agrobanco)

1.  **¿Cuál es la criticidad de las operaciones offline?** Dado que el sector rural tiene conectividad intermitente, ¿deberíamos permitir que las transferencias se "encolen" localmente y se ejecuten automáticamente al recuperar señal, o el usuario debe re-confirmar manualmente?
2.  **¿Existe una red de corresponsales rurales o agencias físicas específicas?** Esto es clave para la Vista de "Depósitos", ya que podríamos incluir un mapa o lista de puntos de atención cercanos donde el código QR generado sea válido.
3.  **¿Cómo se maneja la alfabetización digital en el soporte?** Para el botón de "Soporte", ¿priorizamos el chat de WhatsApp (más familiar) o una llamada directa al 0800-AGRO? ¿Se contempla asistencia por voz o tutoriales en video cortos?
